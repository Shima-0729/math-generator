# 算数プリント作成ツール

条件から整数・有理数の算数問題を生成し、PDF・CSV・画像付きZIPとして保存したり、15問の整数問題テストに挑戦したりできる静的Webサイトです。生成・ファイル作成・採点・時間計測はブラウザ内で行い、入力内容を外部へ送信しません。

## 主な機能

- 計算＋逆算、計算のみ、逆算のみを選択
- PDF・CSVは整数のみ、有理数のみ、整数＋有理数に対応
- PDFは15問または30問、CSVは1～1000問
- 整数と有理数に共通の2項、3項、4項を選択
- 整数の数値上限を10～10000から指定
- 有理数の計算結果の上限は1～10、分母設定は2～10の整数
- 任意seedによる問題の再現
- 生成した問題と解答の一覧プレビュー
- KaTeXによる分数・帯分数・小数のプレビュー
- 日本語フォントを埋め込んだA4 PDF。30問でも問題用紙1ページ＋解答1ページ
- 従来の「問題,答え」2列形式のUTF-8 BOM付きCSV
- LaTeXのCSVと問題・解答の透明背景PNGをまとめたZIP（1～1000問）
- 1000問の候補から重複なく選んだ15問の算数テスト
- 問題ごとの解答時間、回答回数とテスト全体の集計
- スマートフォン、タブレット、PC向けのレスポンシブ表示

## 使い方

トップの機能選択から、PDFプリント作成、CSV問題作成、算数テストのいずれかを選びます。各画面で問題タイプ、項数、数値上限などを設定してください。

フォルダー構成を保って静的Webサーバーに配置し、HTTPまたはHTTPSで開いてください。HTMLを直接開く `file://` 形式では、WorkerやPDFフォントの読み込みが制限されます。ビルドやWeb上でのPython実行は不要です。

初期設定は「整数のみ」「計算＋逆算」「3項」、整数上限500です。有理数設定の初期値は計算結果の上限2・分母設定6です。

「整数＋有理数」では整数問題数を0～全問題数で指定し、残りを有理数問題にします。初期値は全問題数の半数を切り上げた値です。両方を生成した後、問題順をシャッフルします。問題タイプ・項数は共通です。

seedを空欄にした場合は、生成するたびに新しいseedが作られます。画面に表示された「使用したseed」を入力欄へコピーすると、同じ条件で同じ問題を再現できます。

有理数問題でも問題文・解答・分数／小数の表示・混合後の順番を再現します。Python版と問題列そのものが一致する仕様ではありません。既存の整数のみの「計算＋逆算」「逆算のみ」の乱数処理は維持しています。

## 有理数の生成仕様

ローカル管理の `python/make_problem_keisanmaster.ipynb` の `make_problems_rational` を基準として `js/rational.js` に移植しています。PythonフォルダーはGitの管理対象から除外しています。分子・分母をBigIntで保持し、約分・大小判定・演算結果を整数演算で管理します。

- 各演算結果は正で、`max_num` 以下です。式中の数や逆算の解答には、この上限を超える値も現れます。
- 式へ追加する数は既約分母1を除きます。最終結果は整数になる場合があります。
- 加減算で追加する数の既約分母は2～`max_denominator`。乗除算では設定値を超える分母も使用します。
- 各演算結果の既約分母は `LCM(1, …, max_denominator)` の約数です。
- 問題文では既約分母2・4・5・8・10の数を50％の確率で小数表示します。解答は整数・真分数・帯分数です。
- 「計算＋逆算」は計算が `1 / (項数 + 1)` の確率です。計算と逆算の両方が必ず含まれる保証はありません。
- 約分できる候補を含む乗除算の演算選択の重みは `1.0` です。

PDF・CSV用の生成はWeb Workerで行い、有理数問題の生成中は進捗を表示します。乱数を使わない候補は1回の生成中に再利用します。キャッシュの保持数にも上限を設け、完了またはエラー時にはWorkerを終了してキャッシュも破棄します。

## 表示と出力

- Webの問題と解答は、同梱のKaTeXで数式表示します。CSVのプレビューは先頭20問までです。長い数式は横にスクロールできます。
- PDFはA4縦で、15問・30問とも問題用紙1ページ＋解答1ページです。30問の本文は左列1～15、右列16～30。下部の解答欄・解答も上から下へ番号が進みます。
- PDFの分数はjsPDFで文字と分数線を直接描画し、枠の幅・高さに合わせて縮小します。WebとPDFで同じ問題・解答文字列を使用します。
- CSVページの出力形式は「普通表示」「LaTeX表示」「画像付きZIP」の3択です。初期値はLaTeX表示です。普通表示・LaTeX表示のCSVは `問題,答え` の2列、UTF-8 BOM付き、CRLF区切りです。
- 普通表示は `1/2`、`1 1/2`、`( … )` のようにLaTeXコマンドを使わず、演算記号は `×`・`÷`、空欄は `□` として保存します。
- LaTeX表示は `\frac{1}{2}`、`1\frac{1}{2}`、`\left( … \right)` を維持し、`×`・`÷`・`□` をそれぞれ `\times`・`\div`・`\square` に変換します。整数問題の記号も同様に変換します。
- 出力形式は生成後も切り替えられ、同じ問題を再生成せずに3つの形式で保存できます。Webプレビューは、出力形式にかかわらず数式表示です。
- テストは整数専用です。3種類の問題タイプに対応し、1000問の候補から異なる15問を出題します。回答入力・採点・再回答・時間計測・再挑戦は既存の処理を使用します。

## 画像付きZIP

「画像付きZIP」を選び、問題生成後に「画像付きZIPをダウンロード」を押すと、次の構成の `math_questions.zip` を作成します。

```text
math_questions.zip
├── data.csv
├── questions/
│   ├── q0001.png
│   ├── q0002.png
│   └── ...
└── answers/
    ├── a0001.png
    ├── a0002.png
    └── ...
```

- `data.csv` は `id,question_latex,answer_latex` の3列、UTF-8 BOM付き・CRLF区切りです。LaTeXは `$...$` で囲みません。IDは生成順の `0001`～`1000` で、同じIDの問題画像・解答画像と対応します。ExcelでIDのゼロを保持する場合は文字列として取り込んでください。
- 問題画像には式と□、解答画像には答えの数値だけを入れます。問題番号や見出しは付けません。
- 整数・小数・分数・帯分数ともKaTeXで描画し、html-to-imageでPNGに変換します。画像は黒文字・透明背景で、式に応じた可変サイズです。表示用の分数はプレビューと同じく `\dfrac` で大きく描きますが、CSV内の `\frac` は維持します。
- 書き出し用の文字サイズは24 CSS px、余白は各辺12 CSS px、画像の倍率は2倍です。画面幅・端末のピクセル比によって倍率を変えません。WordやExcelなどではPNG画像として挿入できます。
- 同梱のKaTeXフォントを画像化用のSVGに埋め込みます。フォントの取得・読み込みに失敗した場合はZIP作成を中止します。PNG自体にフォントファイルは含まれません。
- PNGは1枚ずつ作り、fflateでZIPへ順に格納します。PNGの再圧縮はしません。1000問では2000枚のPNGとなり、所要時間と使用メモリは端末や数式によって変わります。保存するZIPのデータはブラウザ内に保持します。
- 画像作成には進捗表示とキャンセルがあります。キャンセル・失敗時も生成済みの問題は残り、再試行や通常のCSV保存ができます。作成中はページを開いたままにしてください。
- 自動保存が始まらない場合は「作成済みZIPを保存」を押してください。新しく問題またはZIPを作ると、この保存リンクは更新されます。

CSVページのCSPは画像内のスタイルとフォント埋め込みのため、`style-src` に `'unsafe-inline'`、`font-src` に `data:` を許可しています。`script-src` と `connect-src` は `'self'` のままです。数式の描画はKaTeXの `trust: false` を使用します。

今回のZIP機能の確認は静的確認のみです。ブラウザでの画像表示・展開・大量出力、およびWord・Excelへの挿入は実機で確認してください。
