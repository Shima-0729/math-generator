# 算数プリント作成ツール

指定した条件から算数問題をランダム生成し、問題用紙と解答をA4 PDFとして保存する静的Webサイトです。問題生成とPDF生成はすべてブラウザ内で行われ、入力内容をサーバーへ送信しません。

## 主な機能

- 普通の計算と逆算を含む問題、または逆算のみを生成
- 15問または30問を選択
- 2項、3項、4項を選択
- 数値上限を10～10000から指定
- 任意seedによる問題の再現
- 生成した問題と解答の一覧プレビュー
- 日本語フォントを埋め込んだA4 PDFの生成
- スマートフォン、タブレット、PC向けのレスポンシブ表示

## 使い方

1. 問題タイプ、問題数、項数、数値上限を設定します。
2. 必要に応じてseedを入力します。
3. 「問題を生成」を押して、問題と解答の一覧を確認します。
4. 「PDFをダウンロード」を押します。

seedを空欄にした場合は、生成するたびに新しいseedが作られます。画面に表示された「使用したseed」を入力欄へコピーすると、同じ条件で同じ問題を再現できます。

## 問題生成ロジック

`js/generator.js`は、以下のPython関数を基準に移植しています。

```python
make_problems(term_num: int, max_int: int, problem_num: int, back=False)
```

演算子の選択、左右への項の追加、括弧の付与、整数で割り切れる除算、低い数を出やすくする乱数分布、□の位置選択を引き継いでいます。乱数生成器はJavaScript向けのseed対応実装であるため、同じseedをPythonへ指定した場合の乱数列とは一致しません。
